基于 TI MSP430F6638 低功耗单片机与 PC 端 PyQt6 软件构建的**软硬协同电子密码锁系统**。本项目不仅完美实现了课程设计的基本要求与发挥部分，还额外拓展了 10 项高级功能，包含多模态交互、双通道通信、掉电存储及语音合成等。

---

## 📖 项目简介

系统采用经典的**“PC上位机 + 单片机下位机”**架构。下位机使用无操作系统的“中断 + 前后台”结构，负责底层的硬件控制、密码校验与数据存储；上位机使用 Python + PyQt6 编写，提供直观的图形化界面，负责密码输入、时间下发与状态可视化。

### ✨ 核心功能亮点

*   **🔐 安全机制**：默认密码 `000000`，支持 4~6 位密码修改；连续 3 次输入错误触发系统锁死（红灯长鸣，需复位）。
*   **📺 多模态显示**：ILI9325 彩屏作为主交互界面，TM1638 数码管实时显示状态，三色 LED 配合蜂鸣器提供声光反馈。
*   **💾 掉电存储**：利用片内 Flash 实现密码及最近 5 次开锁/修改记录永久保存，自带 `magic` 校验与数据版本迁移机制。
*   **⏰ 时间同步**：支持一键按键触发 PC 端下发实时时间，自带独立的帧头校验，**确保校时数据绝不污染密码输入**。
*   **🎵 音频互动**：通过 DAC 实现 BGM 播放与语音合成。具备**“语音抢占”机制**（语音播报时自动暂停 BGM，播报完断点续播）。
*   **🎛️ 触摸调音**：电容触摸滑条 5 级音量调节，屏幕动态显示音量矩形条。
*   **🔌 双通道通信**：同时支持 RS232 (UART) 与板载 USB CDC 虚拟串口，支持任意通道的数据双向透传。

## 🛠️ 系统架构

### 硬件模块
*   **MCU**: MSP430F6638 (12MHz 主频)
*   **显示**: ILI9325 TFT 彩屏 (320x240), TM1638 数码管
*   **输入**: 矩阵键盘, 独立按键 (退格/确认), 电容触摸滑条
*   **音频**: DAC12 (P7.6) + 功放
*   **存储**: 片内 Flash (`0x1F800`)

### 软件分层
*   **驱动层**: `LCD_TFT_ILI9325`, `TM1638`, `UART`, `USB_Comm`
*   **服务层**: `clock` (软件日历), `Flash_Storage`, `App_State`
*   **应用层**: `App.c` (主循环与状态机), `App_UI.c` (页面绘制)
*   **上位机**: Python (PyQt6 + PySerial)

## 💡 核心技术难点攻克 (Engineering Highlights)

在开发过程中，针对实际出现的硬件与软件瓶颈，实现了以下工程化解决方案：

1.  **串口通信防粘包/断截 (PC 端)**
    *   **痛点**：单片机发送的 `SUCCESS!` 容易被 PC 端分两次接收（如 `SUCCE` 和 `SS!`），导致 UI 显示错乱。
    *   **解决**：在 PyQt6 串口线程中引入了 `rx_buffer` 缓冲池机制，以 `\n` 作为帧尾进行分割，凑齐完整一行指令后才会触发解析回调。
2.  **时间与密码数据防污染 (下位机端)**
    *   **痛点**：PC 下发时间（含大量数字）时，极易误入密码输入缓冲区。
    *   **解决**：编写了有限状态机 `UART_TimeSync_Parse`。通过识别 `T:` 前缀帧头，独立分离出时间数据，只有非时间帧的数字才允许进入密码栈。
3.  **内存溢出与字模截断修复**
    *   **痛点**：浮点运算及冗余代码导致 Flash 溢出，字模被强行分配到 `0x10000` 以上地址，而 16 位指针寻址越界导致屏幕出现乱码方块。
    *   **解决**：优化算法，将复杂的浮点正弦计算替换为**查表法**（`const sin_table`），大幅缩减空间，解决寻址越界问题。
4.  **语音与 BGM 的优先级仲裁**
    *   **痛点**：背景音乐与系统提示音（如“密码错误”）发生声卡资源冲突。
    *   **解决**：设计音频状态机，语音触发时记录 `was_bgm_on` 标志，强制挂起 BGM；语音播完后重置定时器，BGM 从当前音符索引恢复播放。

## 🚀 快速开始

### 1. 下位机 (MSP430) 编译与烧录
*   **开发环境**: Code Composer Studio (CCS)
*   **操作**：
    1. 导入 `SPI_LCD_TFT` 工程。
    2. 确认编译器版本为 `ti-cgt-msp430_21.6.1.LTS`。
    3. 点击 Build 并烧录至板子。
